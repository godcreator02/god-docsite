## 定调

三个原则，夜里定的：

1. **按 fumadocs 最原生的方式重写**，不做兼容层——旧代码只当功能参考，实现照地基 0.3 的约定
2. **不考虑任何已存在的站点**——旧项目（hybrid-mmc 等）之后专门一批迁移
3. **只对本仓 docsite 体系的内部正确负责**

## 落下来的形状

| 部分 | 重写后的样子 |
| --- | --- |
| 功能包 | 四个出口：`./routes`、`./site`、`./site-server`、`./styles.css`；路由模块照骨架内容页的模式写 |
| 数据模型 | 直连能力包（identity）；`journal/` 文件名规则挪进 project-model |
| 插件 | 对齐 gwb-docsite 0.3：一步建站、start 幂等、failed 不自动重启 |
| 协议号 | 删了——同仓发版、按依赖序，版本对齐由发版顺序保证 |

被否掉的候选（兼容层、给地基补常驻方法、提交前 MDX 全量编译）记在轨迹卡
`2026-10-13-collab-site-native-rewrite` 里。
