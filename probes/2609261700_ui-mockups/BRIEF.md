## 技术约束

* 一个自包含的 `.html` 文件：CSS 写在文件里；JS 只在确实要演示交互时写一点（切换页签、进出批注模式），不引任何框架
* 字体：**不能用 Google Fonts**（组里在国内，打不开）。中文用系统字体栈（微软雅黑 UI、等线、仿宋、楷体、PingFang SC 等，
  按方向挑，并写好后备）；英文与数字字体可以从 `https://cdn.jsdelivr.net/npm/@fontsource/<名字>@5/<字重>.css` 引，写清后备
* 应用外壳占满视口（`html, body { height: 100% }`），正文区自己滚动；1536×864 和 1920×1080 两种视口下都不能出现整页横向滚动
* 只做浅色；颜色一律写成 `:root` 上的变量，将来好加深色
* 数字列用 `font-variant-numeric: tabular-nums`

## 设计要求

* 这是一个边看边操作的工具，不是一篇文章：先给总体再给细节，状态（未解决、进行中、已完成、高压）用形状和颜色一眼就能看出
* 边框、底色、阴影只给真正需要单独突出的那一个东西，不要每块都做成带圆角带阴影的卡片
* 至少放一处只有这个项目才有的细节，写成内容，不是装饰
* **不要落进这些一看就是 AI 做的样式**：暖米白底配衬线大标题配赭红色强调；近黑底配一个荧光绿或朱红；报纸式细线分栏；
  紫到蓝的渐变；Inter 或 Space Grotesk 当安全字体；拿 emoji 当小标题标记；什么都居中；到处都是一样的大圆角；
  圆角卡片左边加一条彩色竖条
* 界面文字用中文，写得像懂行的人说话；按钮写清楚点了会怎样

## 第二轮修改（用户意见：「过于设计了，版式可以炫，字体别乱动」）

**字体只用三种，其它一律删掉**（包括 @fontsource 的所有引用、仿宋、楷体、宋体、各种西文字体）：

* 全部文字：`"Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif`（标题、正文、界面、表格、数字、批注都是它；
  字重只用 400 / 700，要层次靠字号、颜色、字重，不靠换字体）
* 公式与物理量符号：**用 KaTeX 排版，不是只换字体**。引 `https://cdn.jsdelivr.net/npm/katex@0.16.22/dist/katex.min.css`
  和 `.../katex.min.js`，给公式元素写 `data-tex="..."`，页面加载时用 `katex.render(tex, el, {throwOnError: true})` 逐个渲染
  （不用 auto-render 扩展）。要排的：参数栏的量符号（`P`、`U_\text{dc}`、`U_\text{ac}`、`N`、`U_\text{c}`）；
  「怎么算的」那一列的算式，写成真正的公式，比如 `m = \dfrac{2 \times 220\sqrt{2}}{700}`、
  `\dfrac{I_\text{dc}}{3} + \dfrac{I_\text{ac,峰}}{2}`、`\dfrac{10\,\text{kW}}{\sqrt{3} \times 380\,\text{V}}`；
  正文里出现的量符号也一样。中文放进 `\text{}`；行内公式的字号跟周围文字对齐（`.katex { font-size: 1.05em }` 左右）
* 代码与标识：`"Sarasa Mono SC", Consolas, monospace`。用在路径（`prototype/rack`）、分支名、记录 id、提交号、快捷键这类
  「机器读的字」上；参数数值、表格里的数字不算代码，用微软雅黑

**风格：简约的现代软件**（Linear、Figma、Notion、Vercel 控制台那一类）：

* 版式保留你这个方向的结构，这是可以炫的地方；去掉质感和装饰：不要纸张纹理、方格底纹、切割垫、手绘抖动的线、
  印章、斜纹、仿真的笔迹
* 中性灰为主，一个强调色；状态色（未解决、进行中、已完成、高压）只用在状态标记上
* 线条 1px、颜色淡；圆角统一一个值（6px 左右），只给按钮、输入框、弹出层、选中态；阴影只给浮起的弹出层
* 图标用内联 SVG 线条图标（1.5px 描边，16px），不用字符或 emoji 代替
* 间距用 4 的倍数；控件高度统一（如 28 / 32px）；悬停、选中、焦点态都要有，而且克制
