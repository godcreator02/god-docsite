协作站界面：四个方向

四张都是静态效果图，用的是机架页的真实内容，批注和任务里有几条是示例。可以挑一张，也可以混着要，比如「A 的版式配 C 的状态栏」。

  1. F安静版参照块笔记：没有顶栏，左栏放页面树、本页大纲和人员，右边一列悬浮图标打开批注和任务浮卡，正文只留标题、段落、列表、表格和公式。
  2. E审阅页边 + 批注栏B 的整体风格，批注换成 C 那种右侧批注栏，四周边框尽量窄。
  3. A工程图纸每页是一张带图框和标题栏的图纸，批注按分区坐标定位，列在右侧的修改记录表里。
  4. B审阅页边去掉右栏，批注写在正文页边、和被批的词对齐，像在审一份书稿。
  5. C专业工具像 EDA 软件或 IDE：页面标签、资源树、检查器，底部状态栏显示 git 协作状态。
  6. D实验记录本页面侧边伸出索引标签做导航，页顶一条记录信息和待办清单，批注写在页边。
