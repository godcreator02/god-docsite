## 代码块

```ts title="collections.ts" {3}
import { defineDocs } from 'fumadocs-mdx/macro'

// 集合 A：术语插件只对它生效
export const docs = defineDocs({ dir: 'content/docs' })
```

行内代码里的术语不标：`命令总线`。

## 公式

行内 $e^{i\pi} + 1 = 0$ 与块级：

$$
\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

公式里的词不标：$命令总线 + x$。
