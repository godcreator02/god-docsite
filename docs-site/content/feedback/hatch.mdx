# 孵化

**本页回答**：这个仓里有哪些手动重复过两次以上的操作，值不值得做成命令、skill 或脚本。

一条一节，格式跟 [投来的反馈](/feedback/inbound) 一样：`## <日期> <标题>`，下面写做了什么、
重复了几次、做成什么形态合适。**短期内碰到三次或人点名，就升格**——升格之后把条目划掉、指向新做出来的
那个东西，过期的条目直接删。这一页仓内直接编辑，不经命令。

本仓自己的候选放这儿；别的仓投来的反馈在 [投来的反馈](/feedback/inbound)。

## 2026-09-09 挪一页文档要点两次 confirm

来源：本仓

六区改造挪了十几页，每挪一页都要 `livedoc confirm <旧路径> <新路径>`——旧路径忘记录、新路径重钉。
重复了十几次。做成形态的备选：`livedoc mv <旧> <新>`（挪文件 + 两头点名一趟做完），或者让 `confirm`
认出「同名同内容、路径变了」自动接上。第二种要猜，先看第一种够不够。再撞见一次就动手。
