# 孵化

**本页回答**：这个仓里有哪些手动重复过两次以上的操作，值不值得做成命令、skill 或脚本。

一条一节：`## <日期> <标题>`，下面写做了什么、重复了几次、做成什么形态合适。
**短期内碰到三次或人点名，就升格**——升格之后把条目划掉、指向新做出来的那个东西，
过期的条目直接删。这一页仓内直接编辑，不经命令。

**投来的反馈住同区的 [inbox](/feedback/inbox)**，一条一节、标清来源，处理完删——那页专门收别的
仓的意见。反馈区因此两页分工：inbox 收投来的，这一页装的全是本仓自己的重复操作候选。
