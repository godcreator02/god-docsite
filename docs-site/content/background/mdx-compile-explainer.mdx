## 两个要点

**必须用 `applyMdxPreset` 包一层**。集合上直接写 `mdxOptions: { remarkPlugins: [x] }` 时，fumadocs-mdx 拿来就用、不再套默认工序：标题没了 id、没有搜索记录、没有本页目录、代码不高亮。写成数组时插件插在默认工序中间、structure 之前。本站 `source.config.ts` 的 docs 集合就这么写，插件来自 `sitePlugins`（`app/lib/mdx-plugins.ts` 汇总各功能的接线文件）：

```ts
// 集合设置：数组形式插在默认工序中间、structure 之前
applyMdxPreset({ remarkPlugins: sitePlugins.remarkPlugins })

// 直接写（错了）：默认工序全部消失
{ remarkPlugins: sitePlugins.remarkPlugins }
```

**dev 下改被钉的代码，页面不会跟着变**。fumadocs-mdx 给 remark 插件留了 `addDependency`（remarkInclude 就用它），remarkCodePin 没用它，所以 dev 下改了被钉的代码，页面不会变，要再存一下这一页的 .mdx 或重启开发服务。
