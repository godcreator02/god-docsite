编译一个 .mdx：从一段文本到一个 JS 模块

全流程图里，Vite 把 install.mdx 交给 fumadocs-mdx，出来就是 JS 模块，中间只画了一格。这一页把那一格拆开：左边是原文和设置，中间是按顺序排的工序，右边是语法树怎么一步步被改、最后导出了什么。我们的钉码就挂在这条工序里（橙色）。

按 fumadocs 16.17.1 源码（默认编译器 @mdx-js/mdx）。右栏的源码行都能点开看原文件。

同一套 Markdown 规则，有几个出口

上图第 9 道工序后面，钉码插件用 replaceSource 登记了 <Pin> 的 Markdown 形式。这张图看同一个正本走两条路：站点里编译（搜索、fumadocs 的 LLM 输出），以及命令行里生成 AGENTS.md 这类生成物。橙色是我们的包，虚线是可选、现在不开的。
