## 为什么改

这个包实际只给 docfirst 站用：六个使用方全是 docfirst 站，`./text` 入口是给 docfirst 的机读版生成文字用的，
用法写在 docfirst 插件的说明书 `docs-site` 里。叫它通用包、名字里不带 docfirst，读的人会以为普通站也在用它。

## 改成什么样

- 包名 `@godcreator/docfirst-explainer`，独立发版，版本号从 0.1.0 开始；样式类名前缀 `dx-`、`sm-` 不改
- 它归 docfirst 一侧，但仍然**自成一体**：清单里没有任何 `@godcreator/` 包，源码与产物不 import 它们；
  `docfirst-workflow` 与工作台插件都不依赖它，只有站用
- 边界测试分两张表：「自成一体的包」（code-pin、trajectory-disk、docfirst-explainer）查不依赖兄弟包；
  「通用包」（code-pin、trajectory-disk）另外查不认识 docfirst
- 决定写成一张轨迹卡，这一页做完删掉
