认记号走 remark 语法树：记号是 `mdxFlowExpression` 节点，段落里以 `@@docfirst` 开头的一行报错；一篇里写坏的记号走完整棵树一次列全再报错。

## 依赖

| 依赖 | 用来做什么 |

## 不做的事

- **命令行那一侧不认识任何站的宿主**：除了 `src/fumadocs/`，fumadocs、react、next 在源码与产物里都不出现，清单里它们只是可选 peer。
  命令行运行在 git hook 与 CI 里，那些环境不一定装了站的依赖：

{/* ref file="../tests/boundary.test.ts" lines="433-445" hash="8ddaab08f765" blob="b3c39878725f" */}

- **命令行那一侧不认识 fumadocs 适配**：别的目录不许引用 `src/fumadocs/`，`src/fumadocs/` 也只按包名用 `.`、`./mdx`、`./cards`：

{/* ref file="../tests/boundary.test.ts" lines="417-431" hash="6cf7852c8dc4" blob="b3c39878725f" */}

- **不判状态**：绿黄白红由[钉码核心](/docs/pin)算，这个包把磁盘、git、配置交给它，再把结果打印出来。
- **不给盘建模、不画盘**：关系怎么连成树、主干怎么选、盘怎么画归[星轨盘](/docs/trajectory)；这个包只把卡文件换成它要的中性输入。
- **摆放不读写文件**：`placement.ts` 经 `PlacingHost` 读写落点，读写磁盘的那份实现在 `load.ts`，测试换成内存那份：

{/* ref file="../packages/docfirst-workflow/src/project/placement.ts" lines="77-91" hash="90be89518ac3" blob="6dc0e3cf3ba7" */}

- **不建站**：建站命令与模板归[工作台插件](/docs/plugin)。
