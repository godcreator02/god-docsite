{/* ref file="../packages/docfirst-workflow/src/mdx/index.ts" lines="20-41" hash="00a0ec519d2a" blob="26de56e31ba1" */}

认记号用 remark 语法树：记号是 `mdxFlowExpression` 节点，段落里以 `@@docfirst` 开头的一行报错；一篇里写坏的记号遍历完整棵树、一次列全再报错。

fumadocs 自带组件的规则在 [fumadocs 适配](/docs/fumadocs)的 `./roster`。规则三种写法，函数规则只经 helpers 读节点、造节点：

{/* ref file="../packages/docfirst-workflow/src/mdx/roster.ts" lines="24-35" hash="efedd191320a" blob="79ca02da1010" */}

`stamp` 给站上每页的机读版用（站的集合接了 `docfirstMarkdownOptions` 才有）：按名册给树上每个组件标上机读文字（写在节点的 data 上）、不换节点（同一棵树还要生成页面），名册外的组件不标、不报错；把机读文字序列化成 md 的回调在 fumadocs 适配。`docfirst.create` 新建的站不接它，机读文字只出现在生成物里：

## 依赖

| 依赖 | 用来做什么 |
| --- | --- |
| 钉码核心 `@godcreator/code-pin`（通用包） | `createPinner`、目标与记录的类型、细分理由的中文说法 `REASON_TEXT`、hash 与 hunk 解析 |
| 星轨盘 `@godcreator/trajectory-disk`（通用包） | 中性输入的类型、校验时刻的 `validBornAt`，`buildModel` 给 `docfirst trajectory` 建模 |
| unified、remark-parse、remark-mdx、remark-frontmatter、remark-math | mdx 格式的语法树；remark-math 让公式里的花括号不被当成 mdx 表达式 |
| fumadocs-core、fumadocs-ui、react、unist-util-visit | 只有 `src/fumadocs/` 用；前三个是可选 peer，只用命令行的项目不装 |
| `git` 命令行 | 取旧内容、算 hunk 表、查未提交改动、按 `.gitignore` 过滤；被引的文件与目录都不在 git 仓里时不启动 |
