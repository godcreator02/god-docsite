包 `@godcreator/explainer-player`，源码在 `packages/explainer-player/src/`，出口是 `.`（客户端组件，`src/index.ts`）、`./text`
（`src/text.ts`）、`./seam-graph`（`src/seam-graph.ts`）与样式表 `./styles.css`（`styles/explain.css`）。

它是通用包，叫讲解播放器：把一段讲解拆成若干帧、每帧配一句说明，用固定的控制条播放和切换。它不认识 docfirst，
普通 fumadocs 站也能单独装它；本仓的文档站是它的一个使用者。它跟 docfirst 的包互不认识，所以首页的全局接缝图里没有它；

## 功能

**三种外壳**：分步 `Stepper`、动画 `Timeline`、选情况 `CasePicker`。控制条在画面上方排成固定的一行，说明行（当前这一帧的 `title` 与 `text`）在画面下方。

`Stepper` 讲有先后的过程：每一步是一个固定状态；播放是每隔 `interval` 毫秒下一步，到最后一步停：

{/* ref file="../packages/explainer-player/src/stepper.tsx" lines="14-22" hash="392da250a524" blob="dafaf7713972" */}

`Timeline` 讲连续变化：时间是秒数，每章给 `duration`；播放按 `requestAnimationFrame` 推进，横条能拖到任意一刻。
画面是「这一刻 → 画面」的函数，所以往回拖也画得出来：

## 不做的事

**不认识 docfirst，也不认识别的包。** 它是通用包：清单里没有任何 `@godcreator/` 包，源码与产物不 import 它们，
源码的相对 import 不出自己的 `src/`：

{/* ref file="../tests/boundary.test.ts" lines="192-216" hash="5a122995ee1f" blob="269b4f418ee0" */}

包目录里（源码、产物、样式、构建配置、清单）一个 docfirst 字样都没有：

{/* ref file="../tests/boundary.test.ts" lines="218-229" hash="8111ed1a5a3b" blob="29557311bd0a" */}

**也不被 docfirst 的包认识。** docfirst 的包与工作台插件都不依赖它，只有站用它；清单里没有 `dependencies`，react 只作必需 peer：

{/* ref file="../tests/boundary.test.ts" lines="566-574" hash="3a7782b7dcfb" blob="f364ea40ffcc" */}

**不把 react 打进产物。** `.` 的产物第一行是 `"use client"`，只许 import react：

{/* ref file="../tests/boundary.test.ts" lines="576-586" hash="638c3fd560fa" blob="f364ea40ffcc" */}

**`./text` 不 import 任何东西。** 站在 Node 里生成机读版时加载它（本仓是 `docfirst.config.mjs`），所以它不带客户端指令、源码和产物都零 import：

{/* ref file="../tests/boundary.test.ts" lines="588-593" hash="4363223b8781" blob="f364ea40ffcc" */}

**`./seam-graph` 只 import 类型。** 接缝图的数据文件既被画面 import，又被机读规则在 Node 里加载，所以它的产物零 import、不带客户端指令：

{/* ref file="../tests/boundary.test.ts" lines="595-603" hash="1ede44577a51" blob="6e2375b43a16" */}

**不画题目的画面。** 画面里画什么、每一帧的讲解数据、机读规则都写在各站自己的组件里；这个包只给外壳与零件。
接缝图也一样：一个站有几张图、每张图的内容与坐标、按什么名字挑图，都在站里。
