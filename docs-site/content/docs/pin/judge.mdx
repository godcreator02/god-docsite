每次 `check` 都拿今天的代码跟[记号](/docs/pin/markers)上的记录比，给每一处四种状态之一：

{/* ref file="../packages/docfirst-pin/src/types.ts" lines="66-67" hash="d2a2e323f0a3" blob="32a0167e8d8f" */}

| 状态点 | 状态 | 什么意思 | `check` 算不算红 |
| --- | --- | --- | --- |
| 绿 | 新鲜 | 被钉的内容跟确认时一样，位置变了也算 | 不算 |
| 黄 | 有变动 | 内容变了，等人读一遍那句话再确认 | 不算；本仓未提交的改动引起的算，见[提交门禁](/docs/pin/gate) |
| 红 | 缺失 | 被钉的东西不在了 | 算 |
| 空心 | 未确认 | 记号上还没有确认时写的记录 | 不算 |
