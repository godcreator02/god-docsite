## 功能

**三种模板**：控制条在画面上方排成固定的一行，说明行（当前这一步的 `title` 与 `text`）在画面下方。

`Stepper` 讲有先后的过程：每一步是一个固定状态；播放是每隔 `interval` 毫秒下一步，到最后一步停：

{/* ref file="../packages/docs-explain/src/stepper.tsx" lines="14-22" hash="392da250a524" blob="dafaf7713972" */}

`Timeline` 讲连续变化：时间是秒数，每章给 `duration`；播放按 `requestAnimationFrame` 推进，横条能拖到任意一刻。
画面是「这一刻 → 画面」的函数，所以往回拖也画得出来：

{/* ref file="../packages/docs-explain/src/timeline.tsx" lines="17-32" hash="7df491c52f49" blob="40324b1df520" */}

## 不做的事

**不认识 docfirst 的任何包，也不被它们认识。** 普通 fumadocs 站也装它，所以清单里不许出现任何 `@godcreator/` 包，
工作台插件也不依赖它：

{/* ref file="../tests/boundary.test.ts" lines="449-459" hash="b53e494465c5" blob="620efd5d3544" */}

**不把 react 打进产物。** `.` 的产物第一行是 `"use client"`，只许 import react：

{/* ref file="../tests/boundary.test.ts" lines="461-471" hash="c24aef42a31c" blob="620efd5d3544" */}

**`./text` 不 import 任何东西。** `docfirst.config.mjs` 在 Node 里加载它，所以它不带客户端指令、源码和产物都零 import：

{/* ref file="../tests/boundary.test.ts" lines="473-478" hash="1cb40f589530" blob="620efd5d3544" */}

**不画题目的画面。** 画面里画什么、每一步的讲解数据、机读规则都写在各站自己的组件里；这个包只给外壳与零件。
