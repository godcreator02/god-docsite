本页由人写。agent 不改这页，只能在别处提建议。


# 核心愿景

ai agent干活的时候会写下非常多的文档和代码，在每一轮审查过后又会根据人类的需求去修改这些文档和代码。但是往往ai agent修改的时候只会盯着人说的地方改，并且可能还会在注释里面留下一大堆“之前是xx方案，现在是xx方案”等垃圾内容。再一个由于大模型的底层原理，文档本身只能进去上下文的很小一部分，那些被改动位置的文档往往不会被大模型注意到而漏改。

有一个笑话：“我让gpt做一盘番茄炒蛋，他添油加醋觉得更好吃做了一盘红烧肉，等我回来修正的时候发现gpt在代码里写了一堆为什么番茄炒蛋不需要按照红烧肉做法的注释”。
