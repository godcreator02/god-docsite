包 `@godcreator/gwb-docfirst-workflow`，在 `plugins/docfirst/`，源码在 `src/`，入口 `src/index.ts`；说明书在 `skills/`，
建站模板在 `template/`。它是 god 工作台（gwb）的插件，不发成 npm 库。

它建与托管的是 Next 站，站接的是 workflow 的 [fumadocs 适配](/docs/fumadocs)。建在文档站基础包上的站（本仓的文档站就是）不经这个插件：
初始化、更新骨架与托管归工作台的 gwb-docsite 插件，docfirst 经[站的功能包](/docs/site)接进去。

## 功能

**命令总线上的六条命令与一个窗格**。插件的身份是插件名、命令名、窗格 id 与唯一一条必需注入：

{/* ref file="../plugins/docfirst/src/index.ts" lines="28-38" hash="62b593590304" blob="79e92070bd06" */}

两条建站命令的参数都是 `{ dir, title?, port? }`；托管命令的参数是 `{}`、`{ dir }` 或 `{ dir, build? }`，由 `site-args.ts` 校验，同样多给一个键就报错。

参数是外部输入，两条建站命令用同一个函数校验，多给一个键直接报错；`dir` 必须是绝对路径，上一级（仓目录）必须已经存在，

## 不做的事

**不依赖本仓 `packages/` 下的包**，通用包与 docfirst 自己的包都算。包名从 `packages/` 下的清单现读，三类依赖都不写、源码不 import，不启动它们的命令行：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="123-145" hash="d4668b255389" blob="1edd315ad5d3" */}

**不转发命令行，不读核对结果。** 子进程只在两处启动：`scaffold.ts` 运行官方脚手架，`site-process.ts` 运行托管的站自己的 `build` 与 `start`，都带超时：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="151-171" hash="a26e1047dca0" blob="1edd315ad5d3" */}

**不经别的插件建站。** 依赖表、源码、注入与命令调用里都没有站点插件 `@godcreator/gwb-docs-site`，理由见
[站点插件并入](/trajectory/2026-09-26-site-plugin-merges-into-docfirst)：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="184-196" hash="70d1ca67ed97" blob="1edd315ad5d3" */}

**不给已有的站接入 docfirst，不改仓根。** 站目录必须还不存在；仓根已有、第一次 render 会覆盖的 README / AGENTS / CLAUDE 只写进回执。

**托管不找站、不自动重启，窗格不放按钮。** 只托管登记过的站，不扫描容器根；意外退出只记原因；窗格只读 `docfirst.site.list`，开关都由 agent 调命令：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="198-209" hash="fe9d858e6c29" blob="1edd315ad5d3" */}

**不装依赖、不渲染、不核对。** 只写文件，接着要在站目录里运行的命令写进回执的 `next`。
