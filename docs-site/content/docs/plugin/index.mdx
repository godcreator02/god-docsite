| `gwbCommands` | `@godcreator/gwb-commands` | 必需注入，peer `^0.5.6` | 插件不加载 |

## 不做的事

**不依赖本仓 `packages/` 下的包**，通用包与 docfirst 自己的包都算。包名从 `packages/` 下的清单现读，三档依赖都不写、源码不 import，不启动它们的命令行：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="117-139" hash="d4668b255389" blob="792784f3e1dc" */}

**不转发命令行，不读核对结果。** 唯一的子进程是 `scaffold.ts` 运行官方脚手架，带超时：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="145-161" hash="0e0c85cbf401" blob="e9f29c42aff0" */}

**不经别的插件建站。** 依赖表、源码、注入与命令调用里都没有站点插件 `@godcreator/gwb-docs-site`，理由见
[站点插件并入](/trajectory/2026-09-26-site-plugin-merges-into-docfirst)：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="170-182" hash="70d1ca67ed97" blob="e9f29c42aff0" */}

**不给已有的站接入 docfirst，不改仓根。** 站目录必须还不存在；仓根已有、第一次 render 会覆盖的 README / AGENTS / CLAUDE 只写进回执。

**不管站的运行，不注册窗格。** 端口只在建站时选一次，启动与停止站不归本插件；插件只在建站那一刻做事，没有要一直显示的界面：

{/* ref file="../plugins/docfirst/tests/artifact.test.ts" lines="184-188" hash="8db102ca10f4" blob="e9f29c42aff0" */}

**不装依赖、不渲染、不核对。** 只写文件，接着要在站目录里运行的命令写进回执的 `next`。
