god-docsite 仓是文档站平台、按功能划分的功能包与两个 gwb 工作台插件。任何站点都是「fumadocs 官方 React Router 模板 + 挑选的功能包」：文档站、协作站、带报告的站只是装的功能包不同。

包、插件和站点之间谁调用谁、谁读谁写的文件：

<RepoMap />

## 站点怎么组成

平台包 `@godcreator/god-docsite` 带唯一的站点模板与建站器；建站时复制模板，加功能时把功能包 `template/` 里的接线文件补进站点 `app/features/<功能>/`，再重写汇总文件。平台模板写出的站点文件只改平台包的 `template/`，功能的接线文件只改各功能包的 `template/`。细节在 [god-docsite](/packages/god-docsite)。

## 包

全部在 `packages/` 下，包名都是 `@godcreator/<目录名>`：

{/* tree dir="../packages" depth="1" hash="15660022e4a0" */}

| 包 | 做什么 |
| --- | --- |
| [god-docsite](/packages/god-docsite) | 平台：站点模板与建站器、MDX / TSX / HTML 三种页面来源、布局与侧栏、搜索、llms、推送、术语标注、vite 插件 `godDocsite()` |
| [identity](/packages/identity) | 身份：`people.json`、身份码认人、给浏览器的公开投影 |
| [comments](/packages/comments) | 评论：评论文件、唯一一份写入 action、本页评论的收件箱、正文下方的评论浮窗与正文定位、全站评论表格 |
| [explainer](/packages/explainer) | 讲解组件，以及它们给生成物用的机读文字 |
| [code-pin](/packages/code-pin) | 钉码：把文档里的话钉在代码上，核对代码变没变、确认写回记录，站上显示带状态的钉码外框 |
| [doc-export](/packages/doc-export) | 生成物：从 mdx 正本生成 README / AGENTS.md / SKILL.md，并核对两边一致 |
| [trajectory](/packages/trajectory) | 轨迹卡：卡格式与校验、卡页、星轨盘 |
| [docfirst](/packages/docfirst) | 命令行 `docfirst`：读 `docfirst.config.mjs`，把核对、确认、生成、列轨迹分派给 code-pin、doc-export、trajectory |
| [collab](/packages/collab) | 项目协作：任务与模块、日志与日历、通知、合并检查（命令行 `collab-merge-check`）、记录链接、协作站的项目首页 |
| [word-report](/packages/word-report) | 报告：JSON 报告文档的校验与分章组装、站点 `reports/` 下的报告列表与报告页、命令行 `report-docx`、驱动本机 Word 的导出引擎 |

基础站默认装 `identity` 与 `comments`。

## 依赖方向

功能包之间只许下面这几条依赖；`god-docsite` 不依赖任何功能包，功能包也不依赖 `god-docsite`；包内 `core/`、`node/`、`site/`、`cli/` 的分层与模块之间不许有环也在同一份规则里。没有豁免清单，报出来的都要改掉。检查命令是仓根 `pnpm test:deps`（要先 `pnpm build`）：

{/* ref file="../tests/dependency-rules.cjs" lines="9-21" hash="cc76cda75966" blob="f75367612755" */}

| 包 | 依赖 |
| --- | --- |
| `comments` | `identity` |
| `doc-export` | `code-pin` |
| `collab` | `identity`、`comments` |
| `docfirst` | `code-pin`、`doc-export`、`trajectory` |
| `word-report` | `comments`（规则许这一条，现在的代码没用到） |

## 两个 gwb 插件

全部在 `plugins/` 下：

{/* tree dir="../plugins" depth="1" hash="7c11368a35e8" */}

| 插件 | 做什么 |
| --- | --- |
| [gwb-docsite](/plugins/gwb-docsite) | 本 home 的身份码、建站与加功能（运行时加载平台包的建站器）、`docfirst.create`、托管站点的开发服务、评论命令，给别的插件的服务 `gwbDocsite`；随插件发说明书 docsite、docs-site、docs-writing、trajectory |
| [gwb-collab](/plugins/gwb-collab) | 协作仓与别的仓两套操作、提交审核、通知交给站点 / 协作窗格 / QQ、项目与任务命令；站点交给 gwb-docsite 建与托管 |

## 这个站

`docs-site/` 是全仓唯一的文档站，装的是 `god-docsite`、`identity`、`comments`、`explainer`、`code-pin`、`trajectory`，命令行 `docfirst` 装在 devDependencies。侧栏的区：[总览](/docs)（本页与生成物的正本）、[建站与写页面](/docsite/writing)、[包](/packages/god-docsite)（一个包一页）、[插件](/plugins/gwb-docsite)、[Gitea 与 NAS](/gitea)、[维护](/maintain)、[背景：fumadocs 原理](/background/overview)。轨迹卡在站点根的 `trajectory/`，星轨盘在 [/trajectory](/trajectory)。
