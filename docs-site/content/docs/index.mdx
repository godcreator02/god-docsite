## 站点怎么组成

任何站点都是「fumadocs 官方 React Router 模板 + 挑选的功能包」。平台包 `god-docsite` 带唯一的站点模板与建站器；
功能包按功能划分，名字不带站点类型，各自经 fumadocs 与 React Router 原生的扩展点接入站点。站点 `app/features/<功能>/` 里的接线文件由建站器写入，
站点骨架只改平台包的 `template/`，功能的接线文件只改各功能包的 `template/`。

## 包

全部在 `packages/` 下，包名都是 `@godcreator/<目录名>`：

{/* tree dir="../packages" depth="1" hash="6f49ea0c068a" */}

| 包 | 做什么 |
| --- | --- |
| `god-docsite` | 平台：站点模板与建站器、MDX / TSX / HTML 三种页面来源、布局与侧栏、搜索、llms、推送、术语标注、vite 插件 `godDocsite()` |
| `identity` | 身份：`people.json`、身份码认人、给浏览器的公开投影 |
| `comments` | 评论：评论文件、唯一一份评论写入 action、评论面板与正文定位。基础站默认装它与 `identity` |
| `explainer` | 讲解组件，以及它们给生成物用的机读文字 |
| `code-pin` | 钉码：把文档里的话钉在代码上，核对代码变没变、确认写回记录，站上显示带状态的钉码外框 |
| `doc-export` | 生成物：从 mdx 正本生成 README / AGENTS.md / SKILL.md，并核对两边一致 |
| `trajectory` | 轨迹卡：卡格式与校验、卡页、星轨盘 |
| `docfirst` | 命令行 `docfirst`：读 `docfirst.config.mjs`，把 check / confirm / render / trajectory 分派给 code-pin、doc-export、trajectory |
| `collab` | 项目协作：任务与模块、日志与日历、通知、合并检查（命令行 `collab-merge-check`）、记录链接 |

## 依赖方向

| 包 | 依赖 |
| --- | --- |
| `comments` | `identity` |
| `doc-export` | `code-pin` |
| `collab` | `identity`、`comments` |
| `docfirst` | `code-pin`、`doc-export`、`trajectory` |

`god-docsite` 不依赖任何功能包，功能包也不依赖 `god-docsite`；表里没有的边一律不许有。方向由 `tests/dependency-rules.cjs` 检查（仓根 `pnpm test:deps`，要先 `pnpm build`），
包内 `core/`、`node/`、`site/`、`cli/` 的分层与模块之间不许有环也在那里；没有豁免清单，报出来的都要改掉。

## 三个 gwb 插件

全部在 `plugins/` 下：

{/* tree dir="../plugins" depth="1" hash="03bf6b3bc0a1" */}

| 目录 | 插件 | 做什么 |
| --- | --- | --- |
| `docsite` | `@godcreator/gwb-docsite` | 本 home 的身份码、建站与加功能（调平台包的建站器）、托管站点的开发服务、读写评论的命令；给别的插件的服务 `gwbDocsite` |
| `docfirst` | `@godcreator/gwb-docfirst-workflow` | `docfirst.create`：经 `gwbDocsite` 建站、加 code-pin / trajectory / explainer、把 `docfirst` 包的起始物复制到站点根上；随插件发说明书 `docs-site`、`docs-writing`、`trajectory` |
| `collab` | `@godcreator/gwb-collab` | 项目协作：协作仓与别的仓两套操作、通知交给站点 / 协作窗格 / QQ / AI、项目与任务命令；站点交给 gwb-docsite 建与托管 |

## 这个站

`docs-site/` 是全仓唯一的文档站，装的是 `god-docsite`、`identity`、`comments`、`explainer`、`code-pin`、`trajectory`，命令行 `docfirst` 装在 devDependencies。
侧栏四个区：总览与原理（本页、[fumadocs 原理](/docs/fumadocs/overview)、生成物的正本）、写页面、Gitea 与 NAS、[维护](/maintain)。
轨迹卡在站点根的 `trajectory/`，星轨盘在 [/trajectory](/trajectory)。
