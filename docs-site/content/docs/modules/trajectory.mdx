# 轨迹包

**本页回答**：`@godcreator02/docfirst-trajectory` 管卡与盘的哪两摊、它对 docfirst 那套记录簿一无所知到什么程度、
盘上的位置与颜色各编码什么、怎么不起站单独测。

## 管什么

### 两摊事，方向跟 docfirst 相反

一摊是**卡**：一种只增不改的记录格式，连同读它、校它的那一层。另一摊是**盘**：把一目录卡算成一张星轨盘的
建模、布局与画布层。

docfirst 治的是**现状文档撒谎**——一句话写下的那一刻就跟代码分了家，机制盯着代码变没变。轨迹卡治的是
另一头，**历史被改写**：一次方向了断记下来就该冻结，谁取代了谁、谁是从哪条路转过来的，得看得见。两件事
方向相反，一个盯代码，一个盯文档自己，所以轨迹**不是又一种文档格式**：五类引用说的是「文档对文件系统说的话」，
卡的关系边说的是「文档对文档说的话」，**卡不进记录簿、不需要 confirm，只要即时校验**。两者只在一处相遇
——一篇现状文档链到一张卡，此外互不打扰。

### 卡住哪、盘在哪

卡直接写进项目文档站的 `content/trajectory/`，**一卡一文件、目录内平铺不建子目录**——探索史跟代码走同一批
提交、同一条历史。扫描器照着这条规矩只扫一层，遇上目录不存在一律回空集合、不建目录、不报错：「这里还没有
轨迹记录」本来就是合法状态，不该逼人先造个空目录。

{/* ref file="../packages/docfirst-trajectory/src/scan.ts" lines="26-38" */}

扫盘读文件是并发的，产物却是**确定性的**：`Promise.all` 的完成序不定，出门前按卡身份与文件路径钉死序——同一份目录两次扫描逐位相等，布局层那份黄金样本断言靠的就是这条。

@@docfirst ref ../packages/docfirst-trajectory/src/scan.ts:60-62 @@

本仓自己的卡由人写、动手权在人（AI 只提醒不代写），所以本站那张盘上星星寥寥是正常态，不是接线坏了。盘满了

布局引擎是一个类，纯计算不碰 DOM。产物（落点表、扇环表）由实例自己持有、不挂回共享的卡对象上——多张盘要
同开（虫洞穿越），挂在共享对象上的布局属性会被后建的盘覆盖：

**其一，半径 = 有效天数标度，空窗折叠。**时间轴的世界深度是定死的（`AXIS_SPAN`），数据拉伸填满这段深度、
不撑深度——盘是固定仪表盘。相邻卡之间的空档超过阈值，中段走**对称双半段对数**（前半正向衰减、后半镜像回升），
两端各留一截 1:1 的呼吸带。这样三个月不动的项目和三天冲一版的项目画在同一张盘上都还能看：

**领域是颜色通道，盘上同色不挨着就等于没分域**——所以跨域一律角向互斥，只有同域内时间不搭界的两棵树才复用

焦点带、新压缩区）的积分原函数直接给出，零积分误差、零量化台阶。三段的显示宽全固定，焦点带永远落在同一段

### 盘上的视觉词汇

**颜色只编码领域。**色板叫「矿彩」——低饱和暖偏的五色（石青 / 赭石 / 松绿 / 胭脂 / 藤紫），按 `model.domains`
的首次出现序分配，亮暗两套；色相避开连线占的两段（转向铜绿、里程碑与盘心泥金），未分道走中性灰、不占色板位；
被取代的卡拿领域色跟一个灰混 40% 再画，所以它还留着自己的泳道身份、只是黯下去。JS 色板按 `html.dark` 选，
第六个领域出现先扩色板、不循环复用：

{/* ref file="../packages/docfirst-trajectory/src/canvas/theme.ts" lines="36-77" */}

**节点是「珠光」。**在立的实心形状填一支径向渐变（中心 = 领域色向白混 22%、边缘 = 本色、焦点偏左上），
外圈一圈**底色描边**——密集处靠这道缝把彩点分开，不靠混黑描边压边。被取代的实心无渐变、半径压到 0.7、

## 数据结构

### 卡的身份就是文件名

**卡的身份是文件名主干**，去掉后缀的那一截。`parent` 和正文关系边拿的都是这个值，所以改名等于改身份
——落定之后别动，真要改就把指向它的地方一起改。

约定的文件名形态是 `<YYYY-MM-DD>-<英文 slug>.md`：日期前置让列目录时排序即时间序，slug 全小写、`-` 连词、

### frontmatter：六个字段，外加一个自由槽位

认卡靠六个卡体系字段（`born-at` / `type` / `parent` / `merged-in` / `label` / `domain`）——一个都不沾的
`.md` 文件不是卡，整份跳过、连病都不报。`status` 不在其列，它是自由槽位，单凭一个 `status` 不足以认定这是
张卡：

{/* ref file="../packages/docfirst-trajectory/src/parse.ts" lines="16-18" */}

形状是这样的：`born-at` 是分钟级 `YYYY-MM-DDTHH:mm`（日级 `YYYY-MM-DD` 兼容），`parent` 与 `merged-in` 收

### 四层校验

卡就成了会变黄的东西，那它记的就不再是「当时的了断」。草稿记号与 md 正式记号两种形态都认：
