## 两个要点

**必须用 `applyMdxPreset` 包一层**。集合上直接写 `mdxOptions: { remarkPlugins: [x] }` 时，fumadocs-mdx 拿来就用、不再套默认工序：标题没了 id、没有搜索记录、没有本页目录、代码不高亮。写成函数时插件接在所有默认工序之后，排在 structure 后面：

```ts
// 集合设置：数组形式插在默认工序中间、structure 之前
applyMdxPreset({ remarkPlugins: [remarkCodePin()] })

// 直接写（错了）：默认工序全部消失
{ remarkPlugins: [remarkCodePin()] }
```

**改被钉的代码要让页面跟着变，靠登记依赖**。插件读别的文件时调 `addDependency`，fumadocs-mdx 把它转成 Vite 的 `addWatchFile`，Vite 就让这一页失效重编。现在的钉码插件（code-pin）没登记依赖：dev 下改了被钉的代码，页面不会变，要再存一下 .mdx 或重启。

```ts
// 钉码插件里（示意）
const code = readLines('src/setup.ts', 3, 9)
compiler.addDependency('src/setup.ts')   // ← Vite 从此盯住这个文件
```
