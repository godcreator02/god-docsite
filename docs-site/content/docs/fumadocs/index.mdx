包 `@godcreator/docfirst-workflow` 里接到 fumadocs 站上的那部分，源码在 `packages/docfirst-workflow/src/fumadocs/`。出口 `./fumadocs`（`src/fumadocs/index.ts`），另有 `./fumadocs/roster`、`./fumadocs/pre`、
`./fumadocs/term`、`./fumadocs/trajectory`，样式表 `./fumadocs/light.css`、`./fumadocs/term.css`、`./fumadocs/trajectory.css`。

## 不做的事

- **不认识 Next**：这个目录里没有一处 `next`，卡页地址由调用方传 `hrefBase`。
- **不认记号、不判状态**：认记号与打标记用 workflow `./mdx`，核对经项目上的钉码编排，状态由[钉码核心](/docs/pin)算，这里只把清单换成树上的节点。
- **不管讲解组件源码里的引用**：remark 插件只处理 mdx 页面；组件源码里写的引用由命令行的 `check` 核对，站上不显示组件的状态。
- **不管生成物**：生成正本的渲染与写到哪归 [workflow](/docs/workflow)。
- **不把宿主、本仓别的包与本包的命令行代码打包进产物**：只按包名 import；`./fumadocs/pre` 的 `"use client"` 在产物第一行，别的出口不带：
