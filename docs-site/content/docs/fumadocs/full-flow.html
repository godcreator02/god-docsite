fumadocs 原理

一张图走完 fumadocs 的全流程

从运行 react-router dev 开始，到页面显示、接管、切页、改文件，再到 build + start 下有什么不同，全在下面这一张图里。每一步只亮起正在干活的那几块，右边同步显示正在执行的那段代码。

左边是浏览器；中间是服务器进程，从上到下是 Vite、React Router、执行后留在内存里的模块；底下是磁盘上的文件。说明前面的色块表示这一步用的是谁的机制。代码按官方示例 examples/react-router 简化。打开「加上我们的功能」，橙色的部分是评论和钉码要加的东西，包名和导出名都是暂定的。
