讲解组件的正本是 `@godcreator/docsite-explainer`（源码在 `packages/docsite-explainer/src/`），出口是 `.`（客户端组件，`src/index.ts`）、`./text`
（`src/text.ts`）、`./seam-graph`（`src/seam-graph.ts`）与样式表 `./styles.css`（`styles/explain.css`）；旧名 `@godcreator/docfirst-explainer`（0.2.0 起）只是转发薄壳，装旧包名的站不用改代码。这一页钉的源码与清单都是正本的。

它是 docfirst 站上用的讲解组件：把一段讲解拆成若干帧、每帧配一句说明，用固定的控制条播放和切换。接了 docfirst 的站装它，
`./text` 给生成物里的机读文字用，用法写在 docfirst 插件的说明书 `docs-site` 里。docfirst 的命令行与工作台插件都不依赖它，
它也不依赖本仓别的包，所以首页的全局接缝图里没有它；下面是它内部的接缝图。

## 功能

**三种外壳**：分步 `Stepper`、动画 `Timeline`、选情况 `CasePicker`。控制条在画面上方排成固定的一行，说明行（当前这一帧的 `title` 与 `text`）在画面下方。

`Stepper` 讲有先后的过程：每一步是一个固定状态；播放是每隔 `interval` 毫秒下一步，到最后一步停：

`Timeline` 讲连续变化：时间是秒数，每章给 `duration`；播放按 `requestAnimationFrame` 推进，横条能拖到任意一刻。

## 不做的事

**不依赖本仓别的包。** 正本跟钉码核心、星轨盘一样自成一体：清单里没有任何 `@godcreator/` 包，源码与产物不 import 它们，
源码的相对 import 不出自己的 `src/`，各站单独装它、单独升它：

{/* ref file="../tests/boundary.test.ts" lines="250-274" hash="f2d7e0bf9e96" blob="da1acdb8b833" */}

它归在地基能力包一族（`docsite-explainer`）。旧名 `docfirst-explainer` 一侧的来历见轨迹卡
[讲解组件包改名 docfirst-explainer](/trajectory/2026-09-28-explainer-renamed-docfirst-explainer)。

**正本也不被 docfirst 的命令行与插件认识。** `docfirst-workflow` 与工作台插件都不依赖它，只有站用它。薄壳那一侧由边界守卫的第六节专门检查——只依赖正本、react 只作必需 peer、三入口原样转发：

{/* ref file="../tests/boundary.test.ts" lines="631-639" hash="71f1c8a59771" blob="da1acdb8b833" */}

**正本不把 react 打进产物。** `.` 的产物第一行是 `"use client"`，只许 import react：

{/* ref file="../tests/boundary.test.ts" lines="641-644" hash="a2c8d48ad6a5" blob="da1acdb8b833" */}

**正本的 `./text` 不 import 任何东西。** 命令行在 Node 里渲染生成物时加载它（本仓是 `docfirst.config.mjs`），所以它不带客户端指令、源码和产物都零 import：

{/* ref file="../tests/boundary.test.ts" lines="644-647" hash="e8da824d45b0" blob="da1acdb8b833" */}

**正本的 `./seam-graph` 只 import 类型。** 接缝图的数据文件既被画面 import，又被机读规则在 Node 里加载，所以它的产物零 import、不带客户端指令。薄壳的三个入口则只各转发正本一处，指令与形状原样带到：

{/* ref file="../tests/boundary.test.ts" lines="648-651" hash="3be7f47b97dc" blob="da1acdb8b833" */}

**不画题目的画面。** 画面里画什么、每一帧的讲解数据、机读规则都写在各站自己的组件里；这个包只给外壳与零件。
接缝图也一样：一个站有几张图、每张图的内容与坐标、按什么名字挑图，都在站里。
