# 轨迹卡

轨迹卡目录下一个 `.mdx` 就是一张轨迹卡，跟代码在同一个仓、同一个提交。目录由站的 `docfirst.config.mjs` 的 `trajectory` 指定（相对站目录），
一般是 `docs-site/trajectory/`。**docfirst 防止现状文档跟代码对不上，轨迹卡防止历史被改写**：一个方向上的结论记下来就不再改，谁取代了谁、谁从哪条路转过来，要看得见。
一个站的全部卡在站上的**星轨盘**（`/trajectory`）画成一条轨迹；**一个站只有一张根卡**，其余每张卡的 `parent` 只写这张根卡的身份。

下面的 reference 是正本：

- `references/trajectory.md`：什么时候值得记、卡的形态（必填块、可选块、举证分档、各种形态、根卡的写法）、禁止事项。**判断「记什么、写成什么样」读它**
- `references/card-format.md`：文件名、实验目录、frontmatter 字段表、`parent` 规则、正文里的关系、里程碑区块、正文写法细则。**动手建卡时读它**

## 什么时候值得记

满足任一条就记，门槛是**改变了下一步做什么**，拿不准就记：

- **走不通**：试过此路不通，而且找到了具体是哪一步行不通
- **转向**：放弃某条路，改走一个新方向
- **被取代**：旧方案被新方案取代
- **采纳**：某个方向经过权衡，确定采用
- **实验有了结论**：做完一个实验或测量，得出了事实结论

不值得记的：已记方向里的正常推进、孤立的执行操作、已经记过的方向、闲聊。走不通、做了选型、实验有了结论这三种**当场建卡**，跟代码放进同一个提交。

## 建卡不用等授权

够格就建，不问。要先说一句的只有两种：改**已有的卡**，以及往根卡 `## 里程碑` 加一行（里程碑由人挑）。
建完在回复末尾说一句「已建卡 X：标题 + 一句概要」，让人知道刚记了什么。

## 建卡流程

1. **判断**够不够格；采纳、转向、走不通只是判断时的说法，不写进卡里
2. **查重**：先列一遍轨迹卡目录，有同主题的卡就补进那张，不新建
3. **判断形态**：按 `references/trajectory.md` 的形态判据选，向用户用一句话说明判断结果与理由。方向上的结论多写成 `choice`，实验结论多写成 `evidence`，判断不了就不写 `type`
4. **写卡**：必填块 `## 背景`、`## 结论与边界` 写实际内容，用得上的可选块加上，用不上的不留空标题；文件名与 frontmatter 照 `references/card-format.md` 填
5. **里程碑**：项目级的结论往根卡 `## 里程碑` 加一行「日期｜标题｜一句话说明」，改根卡前先说一句

写完在站目录运行 `pnpm doc`：必填字段、`born-at` 的格式、根卡只能有一张、`parent` 只能写根卡、关系行的写法、卡里不许钉码，都由它校验，
有问题的卡算红、退出码 1。**建卡时不另写一套校验**，照字段表填就行。

## 复查：决策不是不能改

卡是当时的判断记录，引用它是说「有先例」，不是「不许动」。环境变了就复查，结果是**一张新卡**，不改旧卡：
推翻就在正文里写 `supersedes::` 指向旧卡，维持就写 `pivots-from::` 指向旧卡并说明在什么条件下仍然成立。

## 实验材料放仓根 `probes/`

实验、测量的全部材料放在仓根 `probes/<时间戳>_<目的>/`，一次实验一个目录，判据是**半年后照 README 第一行运行一次能得到同样的结论**。
`probes/` 进 git、不进 pnpm workspace、不进 `docfirst check`。evidence 卡在 `## 依据` 里写相对仓根的路径指过去。目录结构见 `references/card-format.md` 的「实验目录」。

## 卡里不许钉码

钉码只在现状区。卡正文里出现 docfirst 的记号（`{/* ref … */}` 那一类）`check` 报红：卡记的是当时的结论，代码后来怎么变都不该动它。
卡里引证据写 `probes/` 下的路径或 commit 号。

## 验收

- 已按判据判断过够不够格，已列过轨迹卡目录查重
- 形态已向用户说明；必填块齐全，没有空标题
- 正文的关键数字写了 `probes/` 路径或 commit 号，或者明确写「无证据」
- 有前因的写了 `pivots-from`，取代旧卡的写了 `supersedes`，都在正文里
- 项目级的结论已在根卡「## 里程碑」加了一行
- `pnpm doc` 是绿的，回复里已说明「已建卡 X」
