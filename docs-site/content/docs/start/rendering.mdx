仓根的 README.md、AGENTS.md 和插件里的几份 SKILL.md 都不是手写的：`docfirst render` 按 `docfirst.config.mjs` 的 `outputs`，
把现状区里对应的 mdx 正本渲染到这些位置。下面用一篇小 SKILL 正本从头到尾演示一遍，看它变成生成物时哪几行动了、其余几行为什么一个字节都没变。

所以要改生成物就改正本，再 `render`（`confirm` 也会顺带渲染），正本与生成物放进同一个提交；正本里可以钉码，但不能写组件和 mdx 表达式。
