# 站接线手册

这个站本身就是消费方：你现在读的每一块代码，都是 `next build` 那一刻从源码里现拿的，页面里不存副本。
块右上角那个小圆点是状态——绿是新鲜，实心黄是有变动，空心黄是还没确认，红是引用指向空气了。

## 一、装

<Tabs>
  <Tab title="pnpm">
    `pnpm add -D @godcreator02/live-doc-cli @godcreator02/live-doc-project @godcreator02/live-doc-format-fumadocs`
  </Tab>
  <Tab title="别的格式">
    只写 md 或手写 html，就把 `format-fumadocs` 换成 `format-md` / `format-html`，别的一样。
  </Tab>
</Tabs>

fumadocs 在格式包里只是 peer——用你项目里装的那份，包自己不带。

## 二、项目根放一份 livedoc.config.mjs

命令行和站读的是同一份配置：挂哪些格式包、文档在哪、用哪个比较器、组件名册是什么。

{/* ref file="livedoc.config.mjs" lines="12-28" */}

上面这份是本站的配置，没有 `trajectory` 那一项——它是可选的一摊（轨迹卡目录），配了 `check` 才顺带
跑卡校验、`livedoc trajectory` 才有得列，接法见 [轨迹 · 接线](/docs/trajectory/wiring)。

`comparator` 不写就是 `auto`：按被引文件的位置挑记忆——在 git 仓里（本仓、别的仓都算）已提交的走 `git`，
被 `.gitignore` 忽略的、不在任何仓里的走 `hash`。写 `git` 或 `hash` 是强制全用一种。
分派规则见 [状态与比较器](/docs/principles/comparator)。

<Note>
  引用里的路径是**相对项目根**的。这个站的项目根就是站目录，引用的代码在工作区的 `packages/` 下，
  所以记号里写的是 `../packages/…`。
</Note>

目录树引用注入的是 fumadocs 自己的 `Files` / `Folder` / `File`，`mdx.tsx` 的组件表里要有它们（从
`fumadocs-ui/components/files` 拿），压平规则在格式包的默认名册里已经带了。

## 四、三条命令

<Tabs>
  <Tab title="check">
    只读，报每处引用的状态。红（缺失、孤儿记录、名册外组件）退 1，黄和白退 0——黄是「等作者复核」，不是错。
  </Tab>
  <Tab title="confirm">
    出记录、清孤儿、把草稿记号换成正式记号。一处钉不住整篇拒：problems 打出来，记录簿一条不写、文档一个字不改。
  </Tab>
  <Tab title="render --target ai">
    让 fumadocs 自己的管线出 md，产物落 `out/`。人看那份就是站本身。
  </Tab>
</Tabs>

## 五、Next 那头两条设置

{/* ref file="next.config.mjs" lines="7-26" */}

- **`turbopack.root` 要抬到工作区根**。这个站的包从同一个 pnpm 工作区拿，`node_modules` 里是指向站外的
  软链；Turbopack 只认它 root 以内的文件，root 不抬，`packages/` 就在视野外。用发布版包的项目不必管这条。
- **三个包标成 `serverExternalPackages`**。它们只在服务端跑，还要读盘、起 git 子进程——标成外部包让 Node
  自己解析，别让打包器把它们卷进去。**但发布版包（registry 装的）别把 `format-fumadocs` 外置**：
  它的 `/pre` 是客户端组件（状态点），外置后 Next 走 Node 单独加载它、跟站打包的 React 分了家，
  预渲染报 `Cannot read properties of null (reading 'use')`；工作区软链的装法没这个问题。只外置
  `core` 和 `project` 就够——`format-fumadocs` 的服务端那半（remark 插件）走 fumadocs-mdx 的
  loader，本来就是 Node 直载，不经过打包器。第一个 registry 消费方（god-example 的站）踩的就是这条。

## 六、三个坑

<Tabs>
  <Tab title="改了格式包要删 .next">
    Turbopack 只按 mdx 内容缓存：文档一个字没改，它就不重跑 remark 插件，格式包里的改动看不见。
    **先删 `.next` 再 build**。
  </Tab>
  <Tab title="调试用 build + start">
    不用 `next dev`。dev 那条链的缓存和热更新会让「这一版到底跑没跑我的插件」变得说不清。
  </Tab>
  <Tab title="端口可能被占">
    这个站的 `start` 脚本钉的是 4310，被别的进程占了就换一个：`pnpm exec next start -p 4312`。
    起来的站验完记得停掉。
  </Tab>
</Tabs>

接线的每一处分别在讲什么，见 [fumadocs 格式包](/docs/formats/fumadocs)；组件那一半见 [名册](/docs/formats/roster)。
