# 入门

这一部分四章，按第一次接触的顺序排：

1. [需求](/docs/start/requirements)：腐化是什么病，这套机制承诺什么、不承诺什么，术语表。
2. [一分钟上手](/docs/start/quickstart)：装、配、写一行草稿记号、核对、确认、看站。
3. [一条引用的一生](/docs/start/lifecycle)：写下、未确认、确认投影、代码改了变黄、再确认回绿、段没了变红、孤儿。

读完这一部分就能在自己的项目里用起来。想知道它为什么这么做，去「原理」；要接进自己的站，去「格式与站」。
