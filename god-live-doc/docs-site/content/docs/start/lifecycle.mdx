# 一条引用的一生

这一章回答：一处引用从写下那一刻起，都会经过哪些状态，每一步命令行说什么、页面上长什么样。

下面每一段的输出，都是在一个临时 git 仓里真跑出来的：一份 `src/greet.ts`，一篇 `docs/a.md`，
比较器是产品用的 git 版。

## 第一幕：写下——未确认

文档里单独起一行：

```md
@@livedoc ref src/greet.ts:2-3 @@
```

```text
⚪ docs/a.md  src/greet.ts:2-3  未确认，等作者确认
```

空心黄。这时候记录簿里还没有它，站上那一块照样显示代码（内容是现拿的），只是标题栏后面缀着「· 未确认」。

## 第二幕：确认——草稿换成正式记号，内容投影

```text
✅ docs/a.md  src/greet.ts:2-3  已确认，草稿记号已换成正式记号
```

md 那头文档变成这样——记号、展示区、尾记号三件套：

````md
<!-- ref file="src/greet.ts" lines="2-3" -->
```ts
export function greet(name: string): string {
  return `hello ${name}`;
```
<!-- /ref -->
````

mdx 没有展示区，只留一行 `{/* ref … */}`，内容 build 时现拿。记录簿里多出一条：`kind`、blob、commit、
行段、段哈希——**没有代码内容**。再 `check` 一次就是绿的。

## 第三幕：代码改了——黄

改一个字，还没提交：

```text
🟡 docs/a.md  src/greet.ts:2-3  有变动，等作者复核
```

黄不是错，命令行退 0。站上这一块把旧行新行渲在同一块里（`- / +` 用 shiki 的 diff 标记），
让人一眼看出改了什么。

这时候要是急着确认，会被挡下来：

```text
🔴 docs/a.md 第 3 行：src/greet.ts:2-3 未提交——钉住只对已提交的内容做，先 commit
·  docs/a.md  这篇整篇没确认——上面几处先处理掉
```

<Note>
  **一处钉不住，整篇拒**：记录簿一条不写、文档一个字不改，退 1。不是「能钉的先钉上」——
  半本记录簿比没有更难查。
</Note>

## 第四幕：提交后再确认——回绿

`git commit` 之后再 `confirm`，这段新内容成为新的记忆：

```text
✅ docs/a.md  src/greet.ts:2-3  已确认，文档已写回
```

## 第五幕：代码挪了位置——还是绿

在文件上面插两行，函数整体下移，内容一个字没改：

```text
🟢 docs/a.md  src/greet.ts:2-3  新鲜
```

绿。git 记忆拿 hunk 表把旧行段映到今天，段哈希对得上就是新鲜（hash 记忆靠滑窗找，结果一样）。这一趟 `confirm` 会把记号上的
行号改写成今天的位置：

```md
<!-- ref file="src/greet.ts" lines="4-5" -->
```

记录簿里的旧键 `src/greet.ts:2-3` 当孤儿清掉。**记号上的数字不用人维护。**

## 第六幕：段没了——红

把函数删掉，或者把文件删掉：

```text
🔴 docs/a.md  src/greet.ts:4-5  缺失，引用指向空气（整段已被删光）
🔴 docs/a.md  src/greet.ts:4-5  缺失，引用指向空气（文件不在了）
```

红退 1。站上这一块显示的是**文档写下时那段**——从记忆里的 blob 取回来的，好让人知道原本引的是什么。
第三种红是 `blob-missing`：浅克隆或历史重写过，记忆里的 blob 不在对象库了。

## 第七幕：引用被删掉——孤儿

把文档里那处引用整个删了，记录簿里那条就没人认领了：

```text
🔴 docs/a.md  src/greet.ts:4-5  孤儿记录：文档里已经没有这处引用
```

再 `confirm` 一次自动清掉：

```text
🧹 docs/a.md  src/greet.ts:4-5  孤儿记录已清
```

核对（`check` 和站构建走的是同一条）：逐处问比较器要判定，切出今天这段内容，凑成清单项。

{/* ref file="../packages/core/src/service.ts" lines="73-89" */}

孤儿就是「记录簿里有、这一趟没被认领」的那些：

{/* ref file="../packages/core/src/service.ts" lines="90-94" */}

确认：先逐条问比较器要记录，有一处交回 problem 就整篇拒。

{/* ref file="../packages/core/src/service.ts" lines="112-130" */}

都过了才落笔——刷记录簿、清孤儿、存盘，最后让格式包写回文档。
